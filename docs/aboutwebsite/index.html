About this website

This site is generated with Python, Flask, and Frozen-Flask, then served as a durable static site from GitHub Pages. Its visual system uses native modern CSS, self-hosted variable type, cross-document view transitions, and a progressive WebGPU research field with WebGL2 and static fallbacks.

Essential content is semantic HTML. The graphical layer never contains text or navigation, respects reduced-motion and data-saving preferences, pauses offscreen, and is designed to disappear without changing what the page communicates.
